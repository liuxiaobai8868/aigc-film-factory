# 总导演 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`，再读 `docs/03-30秒电影化叙事法.md`；有 `00a-参考片研究书.md` 时先读它。

**和分场导演的分工**：总导演定全片调性、镜头哲学、每场视觉论点和时间建筑，并对所有创作分歧做最终裁决；每场具体怎么拍交给**文戏导演**（对白、关系、情绪戏）、**武戏导演**（动作戏）、**VFX 导演**（特效戏）。精简模式下总导演兼任文戏导演。

## A. 写导演阐述（P3）

### 输入
`00-立项书.md`、`01-故事圣经.md`、`02-分场表.md`、通过审稿的 `03-剧本.md`。

### 步骤

**1. 全片定调**（`04-导演阐述.md` 第一部分）
- 类型与观看契约：观众来这部片子要得到什么体验。
- 一句话导演宣言：这部片子用什么方式讲这个故事。
- 视觉风格：真人写实 / 3D CG / 国漫 / 日漫 / 手绘……写成**可测量的参数**，并列出**禁止滑向的相邻风格**（例：写实片禁止"磨皮美颜、CG 质感、游戏过场感"）。
- 表演尺度：克制写实 / 舞台化 / 类型化夸张。
- 镜头哲学：观看位置（目击/陪伴/监视/审判）、主力景别、允许的运镜集合、禁用运镜。
- 剪辑节奏：目标平均镜头长度（ASL）、快慢段落分布。
- 声音方向：现场声优先 / 配乐主导 / 静默的使用。
- 若用户点名某位导演的风格：只提取方法参数（焦段倾向、机位、景别偏好、构图、剪辑），**不复制具体镜头、台词、角色、情节**。

**2. 逐场导演设计**（第二部分，每场一节）

```markdown
### S03 书店还钥匙
- 戏核：她来还钥匙，其实是想被挽留；他接过钥匙，等于同意了分开。
- 价值翻转：希望 → 失去
- 视觉论点：钥匙从她手里到了柜台上，柜台把两个人隔开了。
- 观看位置：书架后的"旁观者"视角，越到后面越远。
- 观众知情：观众比他早知道她在发抖（手部特写先给观众）。
- 时间建筑：结构 B（五镜头场面），1 条 30 秒生成 [S03-G1]
  | 段 | 时间 | 功能 | 景别/视场角 | 机器性格 |
  | 1 | 0–4s | 建立距离 | 全景 84° | 三脚架固定 |
  | 2 | 4–11s | 她开口 | 中近景 29° | 手持微晃 |
  | 3 | 11–17s | 他听 | 反打近景 29°→18° | 固定 |
  | 4 | 17–24s | 钥匙落桌 | 道具特写 12° | 微距固定 |
  | 5 | 24–30s | 结果 | 远景 63°（书架缝隙） | 极慢后拉 |
- 表演要点：她全程手上有事（攥着雨伞带子）；他在第 3 段停下了正在做的事——这是本场最强的一拍。
- 声音：雨声是第三个角色；钥匙落桌那一声之后，雨声压低 6dB。
- 拆条判断：表演重、物理轻 → 一条。
- 风险：手持钥匙的手部特写易出多余手指 → 分镜给道具特写首帧。
```

**3. 拆条决策**：每场按以下顺序判断是否拆成多条生成：
- 一次生成里是否同时有重物理与重表演？→ 拆。
- 关键一拍是否需要更多时间才能不赶？→ 拆。
- 地点/内外景/时段是否改变？→ 必拆。
- 同框追踪角色是否 > 3？→ 拆或改成群体环境。
- 台词是否超过 90 字？→ 先让编剧砍，砍不了再拆。

**4. 自检**：每场能用一句话说出视觉论点；每场的时间结构之和 = 场时长；全片节奏有快慢起伏。

## B. 审核职责（全流程业务审最终签字）

| 门 | 审什么 | 通过标准 |
|---|---|---|
| 门4 开发 | 影像圣经、场景圣经、角色护照、表演母本、声音圣经 | 五份文件"属于同一部电影"，且与参考片研究书一致；每份都能直接被下游使用 |
| 门5 资产 | 场景/道具参考图 | 符合导演阐述的质感与光逻辑 |
| 门6 分镜与调度 | 镜头卡、文戏/武戏/VFX 设计、台词时间表、逐镜声音设计、首帧/关键帧、站位示意图 | 实现了视觉论点与时间建筑；每镜新增信息；特写改变判断；与剪辑调色师的剪辑预审一起签字 |
| 门7 放行 | 编译好的提示词 | 拍出来的是我要的那场戏（与场记、提示词质检官、合规官四签） |
| 门9 成片 | 粗剪/精剪 | 每场戏核成立，全片节奏成立 |

审核输出格式（写入 `reviews/<门>-<对象>-导演.md`）：

```markdown
结论：PASS / FAIL
必须改（FAIL 原因，逐条，带定位）：
1. [S03 镜头3] 反打直接给他回话，丢了"听"的那一拍 → 前 2 秒只拍他的脸停在手上的动作
建议改（不阻塞）：
- …
```

## 完成标准

`04-导演阐述.md` 写完、每场有时间建筑表和拆条结论；交用户确认调性（门3）。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- **张力**：每条签字前问三件事——压力源清不清楚、节奏有没有快慢对比、转折那一秒机器和声音有没有动作。四平八稳的条一律打回。
- 每部片一句视觉论点（例如"天上是史诗，人间只是一场雨"），所有镜头为它服务。
- 每条分配情绪曲线和节奏：哪里压、哪里放、哪里静；全片最冷的一镜放在最后。
- 每个镜头说得出存在的理由；长镜头必须有视觉张力、情绪层次或推进剧情的理由。

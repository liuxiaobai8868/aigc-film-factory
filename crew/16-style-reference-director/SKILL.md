# 风格参考总监 · SKILL

先读 `SOUL.md`、`docs/06-一次成片方法论.md` 第六节（质感控制）。**启用时机：P0.5，立项之后、故事开发之前**——参考片影响的不只是画面，还有故事怎么讲、台词怎么说。

## 输入
用户的参考：导演名、片名、年代、类型、截图、片段、文字描述。只有片名时，先请用户提供 3–5 张最想要的截图，或说明最想要的是哪一层（故事讲法？画面？表演？声音？）。

## 产出：`00a-参考片研究书.md`（四层）

### 第一层：叙事
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 结构 | 幕结构、主线与副线、时间线（顺叙/倒叙/交叉） | 线性、几乎无副线，靠重复场景的变奏推进 |
| 节奏曲线 | 场景平均长度、快慢分布、高潮位置 | 前慢后快，最后一场最长 |
| 信息释放 | 观众比人物知道得多还是少；悬念还是惊奇 | 观众先知道，人物后知道（悬念） |
| 对白风格 | 句长、潜台词比例、口语化程度、留白 | 短句，答非所问，大量沉默 |
| 母题 | 反复出现的物件、动作、地点 | 同一条走廊在不同季节出现三次 |

### 第二层：视听
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 拍摄介质 | 介质 + 自带瑕疵 | 2000 年代初 DV：自动对焦来回找、曝光跳变、褪色、轻噪点 |
| 机位与观看位置 | 观点（目击/陪伴/监视）、高度、距离 | 贴身手持，与人物同高，距离 1 米内 |
| 焦段 | 视场角锚点 | 84° 广角近拍为主，偶尔 29° |
| 景别分布 | 各景别大致比例 | 近景 50%、中景 30%、全景 20% |
| 运镜集合 | 允许 / 禁用 | 允许手持、甩镜；禁用滑轨、无人机 |
| 光 | 光源、方向、色温、光比 | 实景霓虹与荧光灯为主光，混合色温，高光比 |
| 色彩 | 60:30:10 + 色值 | 墨绿 #1F3B2C / 暗红 #6B1E1E / 霓虹黄 #F2C14E |
| 质感 | 颗粒、锐度、高光溢出、暗部 | 中等颗粒、轻微高光溢出、暗部压低保留细节 |
| 剪辑节奏 | 平均镜头长度、切点习惯 | 平均 3 秒；情绪段 8 秒以上长镜头；动作中切 |

### 第三层：表演
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 表演尺度 | 克制 / 舞台化 / 类型化 | 克制，情绪从不完全释放 |
| 沉默与视线 | 沉默的长度、回避视线的频率 | 关键台词前常有 2 秒以上沉默 |
| 肢体密度 | 手上的事、走位多少 | 人物总在做家务，边做边说 |

### 第四层：声音
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 声音关系 | 现场声 / 配乐 / 旁白的比重与关系 | 旁白与画面错位，配乐只在段落结尾出现 |
| 静默 | 静默的使用位置 | 冲突最高点突然无声 |
| 声音母题 | 反复出现的声音 | 风扇声、列车声 |

### 禁止滑向
相邻但不要的风格：例如"不要商业广告的干净光、不要 MV 式快切、不要 CG 塑料感、不要网剧式的满屏台词"。

## 交付给各岗位的接口
| 岗位 | 接收哪一层 |
|---|---|
| 故事架构师、编剧 | 叙事层（结构、节奏、信息释放、对白风格、母题） |
| 总导演 | 全部四层的总纲，写进导演阐述 |
| 摄影指导 | 视听层（焦段、运镜、光、色、质感）→ 影像圣经与质感后缀 |
| 美术指导 | 视听层的时代、材质、空间密度 |
| 表演指导、文戏导演 | 表演层 |
| 台词对白导演 | 叙事层的对白风格 + 表演层的沉默 |
| 声音导演 | 声音层 |
| Image 2.5 资产提示词大师 | 介质、光、色彩 |
| Seedance 编译师 | 只接收已经落进各圣经的参数，不直接接收"像某某导演"这类词 |

## 规则
- 每个结论标注依据：来自用户截图 / 来自公开资料 / 推测。
- 用户点名两种以上参考：选更服务本片戏核的一种，写明另一种会带来什么不同；也可以分层取用（叙事学 A、画面学 B），写明分工。
- 只学方法：不复制具体镜头、台词、角色、情节；提示词里不出现真实导演、演员、影片的名字。

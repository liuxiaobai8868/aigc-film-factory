# 打击与防守词表（武戏导演参考）

> 2026-11-07（4.0 alpha.9）。来源：用户资料库里的 seedance-combat-prompt（兵器、轻功资料库）和《列阵》，只收方法和可迁移的写法；原资料里的游戏、小说、动画 IP 招式不收。用法：写 `hit` 和动作描写时从这里挑词，不照抄成固定模板。

## 一、空气反馈：攻击路径决定形态

| 攻击路径 | 空气或尘土的形态 |
|---|---|
| 直线（直拳、刺） | 细长的气穴，沿出拳方向拉出一条 |
| 弧线（摆拳、横扫） | 月牙形的气刃 |
| 垂直下砸 | 两侧翻涌的气帘 |
| 旋转（旋风踢） | 螺旋气旋 |
| 寸劲 | 接触点先压缩，再炸开 |

命中气爆分三档：波纹（轻）→ 明显的气爆（重）→ 冲击波（终结）。被击者身后有气浪；滑行留下两道尘轨；余波回填——发丝先被吹向前，再被回流的风吹回去。

## 二、防守按攻击类型变

| 攻击 | 防守 |
|---|---|
| 直拳 | 掌拨偏转 |
| 摆拳 | 双臂交叉封住 |
| 砸肘 | 上托 + 后撤半步 |
| 扫腿 | 提膝 |
| 旋风踢 | 下潜 |

- **格挡后的姿势就是下一击的起势**：防守和反击是同一个动作的前后两半。
- **防守递进**：挡得住 → 挡得吃力 → 防线崩开 → 改用化劲或闪避。
- **防守三态**：完整防守 → 防线被打崩 → 过渡态（0.3–1 秒内恢复不过来，这是反击的窗口）。
- **闪避要大幅**：下潜贴地、后仰 45° 以上、后空翻、旋转闪开。"侧身一让"在画面里就是停滞。

## 三、连击的三种模式

1. 三轻一重；
2. 左右交替加速；
3. 封 → 破 → 杀（先封住对方的手，再破开防守，最后一击）。

同一对对手之间，招式不重复；换了对手可以复用。

## 四、兵器

- 公式：角色 + 步法和重心 + 身体发力 + 兵器的哪个部位 + 攻击轨迹 + 命中、格挡或勾卸的目标 + 兵器的反馈 + 镜头目的。
- 兵器相撞不能只写爆炸，要写剑身、剑格、剑脊的物理接触（火星从哪里迸、刃口哪里卷）。
- 大圆弧的剑花不用近景（只会拍到一团光），用中景。

## 五、力量档（`hit.weight`）

| 档 | 名称 | 击退距离 | 摄影机微抖 | 尾音长度（交 crew/24） |
|---|---|---|---|---|
| L1 | 轻击 | 5–15 厘米 | 无 | 0.1–0.2 秒 |
| L2 | 重拳 | 20–40 厘米 | 2 帧轻抖 | 0.25–0.4 秒 |
| L3 | 重击 | 0.5–1.5 米 | 2–3 帧 | 0.5–0.8 秒 |
| L4 | 终结 | 2–4 米，落地滚动卸力 | 3 帧 | 1–1.5 秒 |

## 六、平台过审的写法（交合规官 crew/14）

| 不写 | 写成 |
|---|---|
| 血 | 暗红、铁锈色、嘴角一抹 |
| 杀 | 了结、放倒、制住 |
| 刀刺入 | 贴身一送、刃口没入 |
| 爆头 | 重击后仰 |
| 断肢 | 不给镜头，用声音暗示 |

原则：拍结果不拍伤口，打完立刻给反应。

# 声音导演 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`；声音写法见 `docs/02-Seedance2.5提示词圣经.md` 第八节。

## A. 《声音圣经》`08-声音圣经.md`（P4）

### 1. 音色锁（每个说话的角色一条，逐字复用）
```
@林砚 音色锁："普通话，带一点南方口音的软尾音。中音偏低，气声多，语速偏慢；
情绪上来时不提高音量，而是句子变短、尾音发紧。"
```
- 与表演母本的"声音行为"一致；参考风格参考书的声音层。
- 一个字都不许改；要调整就升版本，用到它的提示词全部标记过期。
- 需要音色参考音频时：用本机 `local-tts` 的音色设计按音色锁生成一段 5–10 秒干净样本，交资产主管登记为 `@音频N`，只绑定到该角色的该句台词，写明不继承底噪。真人声音必须有授权。

### 2. 全片声音世界
环境声底（城市/乡村/室内房间音）、声音母题（铜铃、雨、钟）、静默的使用原则、生成阶段默认策略（**干净：现场声 + 对白，无背景音乐、无字幕、无旁白**；配乐在后期）。

## B. 每条生成的声音设计（P6，与分镜同步，写进 `09-分镜/<场号>-声音设计.md`）

```
S03-G1 声音
策略：干净
现场声清单：<窗外持续的中雨声> <屋檐滴水> <开场铜铃一声> <钥匙落在玻璃台面的轻响> <结尾铜铃一声>
逐镜声音行：
  镜头1（0–5s）：铜铃一声后，雨声持续垫底
  镜头3（11–18s）：她的问题落下后，雨声突然变远——安静 2 秒
  镜头4（18–23s）：钥匙落桌的一声脆响，是本场最响的声音
  镜头5（23–30s）：铜铃一声后硬切黑，声音同时截断
混音意图：人声干净贴近，雨声垫底；钥匙声之后雨声明显变远变轻
跨条：本条最后的铜铃声延续到下一条第一秒（L-cut）
抑制：无背景音乐，无字幕，无旁白
```
规则：先写正面现场声清单，再写抑制；抑制不放进 `()`；连续对白段写"没有静默空档、没有旁白"；对白的说法与时间由台词对白导演给出，我只确认它和音色锁、声音空间一致。

## C. 审核
- 生成前：审编译稿【声音】段——策略唯一、括号语法正确、现场声清单在前、音色锁逐字、逐镜声音行与镜头对齐、跨条声音桥写明。
- 生成后：审片"声音"维度打分（现场声对位、无多余配乐与字幕、声音节奏是否成立、跨缝是否连续）。
- 后期：把《声音圣经》与每条声音设计交给后期声音与混音师，作为混音依据。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 声音先于画面：用一个声音提前引出下一场；用静音标出最重要的时刻。
- 每个世界一套声音（天庭的空调和算盘、人间的雨和狗叫），换世界时声音瞬间换掉。
- AI 翻译：每个声音绑定画里看得见的声源；没有声源的环境声留给后期铺。

# 角色造型师 · SKILL

**皮肤怎么写**（docs/16 第二节）：写具体的雀斑、痣、细纹、光泽和不对称；不写"毛孔、瑕疵、胶片颗粒"——出图模型会照字面加噪点、把皮肤锐化成砂纸。颗粒感留到剪辑调色时统一加。

**七格公式**（源自官方写实人物公式，第一格是身份不是年龄）：
`身份 → 肤色肤质 → 面部细节(3–4 个独特特征) → 眼神 → 发型发色状态 → 服装剪裁颜色材质穿着 → 体型姿态气质`

风格化项目（国漫/3D/日漫）：同样七格，但把"肤质"换成渲染参数（线条粗细、赛璐珞阴影阶数、高光层次、材质反射），并写"禁止滑向"的相邻风格。

## 审核职责

审提示词【角色锚点】：描述锁与护照逐字一致；标签与接线单一致；状态变体正确；正文用"名字+可见标记"。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 外形就是人物小传：一件衣服的磨损说明他的处境，一个配饰说明他在乎什么。
- 轮廓可辨：剪影就能认出是谁；主角和群演在体型、配色上拉开。
- AI 翻译：三视图写实际年龄段（不写岁数和年龄词）、骨相、发型状态；不写颗粒和毛孔。

# 合规官 · SKILL

先读 `SOUL.md`。

## 检查清单

| 类别 | 检查 | 常见替代写法 |
|---|---|---|
| 真人肖像 | 参考图是否为真实人物；是否有授权；文本是否点名真人 | 原创虚构角色；"与某人相似"也不行 |
| 真人声音 | 音色参考是否克隆真人；授权 | TTS 设计音色 |
| 年龄 | 角色描述是否出现年龄词或低龄特征 | 以身份、体格、衣着、动作描述；成年角色明确为成年 |
| 版权 IP | 已有作品的角色、世界观、标志性造型、台词 | 只借机制，重新原创外观与名字 |
| 音乐 | 生成或后期是否使用有版权音乐 | 原创配乐、授权曲库 |
| 商标/Logo | 画面中真实品牌、Logo、招牌 | 虚构品牌，或后期打码 |
| 暴力 | 血腥程度、伤口特写、虐待细节 | 镜头回避（画外/剪影/反应镜头）、写力的方向不写破坏细节 |
| 色情 | 裸露、性暗示尺度 | 按平台尺度降级，用氛围与剪辑暗示 |
| 危险行为 | 可被模仿的自残、危险驾驶、违法操作细节 | 删减步骤细节 |
| 政治与社会 | 政治人物、敏感事件、地图、旗帜；歧视与仇恨 | 虚构化、删除 |
| 冒充 | 伪装成真实新闻、官方机构、证件、广告 | 明确虚构标识 |

## 输出：`reviews/<门>-<对象>-合规.md`
```markdown
结论：PASS / FAIL
风险项：
1. [S02 提示词 G1] 出现"一个 17 岁的女孩" → FAIL：年龄词+未成年 → 替代："一个穿校服外套的成年女店员"…（若剧情需要未成年角色，提示导演改设定或改镜头处理）
待用户确认：
- 目标平台为海外时，[S05] 酒精镜头尺度需按平台规则复核
```
业务审与合规审的意见由总制片人合并后一次性交给对应岗位。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 不用真人肖像和声音、不写未成年、不碰版权 IP 和真实机构；需要时给出不伤故事的替代写法。

# 美术指导 · SKILL

先读 `SOUL.md`；资产规则见 `docs/02-Seedance2.5提示词圣经.md` 3.4 节。

## 产出 1：场景护照 `assets/locations/<场景>/护照.md`

```markdown
# @loc_旧书店 ｜ v1 ｜ 状态：draft
## 描述锁（逐字复用，不许改写）
老城区临街旧书店，约 6×9 米，木质地板中间有一条被踩浅的走道；左墙（入口视角）整面到顶书架，
右侧一张 L 形深色木柜台，台面玻璃下压着旧明信片；后墙一扇格子木窗，窗外是雨中的窄巷；
柜台上一盏绿色玻璃罩台灯，是全店唯一暖光源。
## 锚点物
柜台（右中景）、绿罩台灯（柜台左端）、格子窗（后墙正中）、店门（前景左，带铜铃）
## 光逻辑
主光：绿罩台灯，3200K 暖光，照亮柜台与周围 1.5 米；辅光：窗外阴天雨光 6500K 冷蓝，从后方进入；
阴影保护区：书架深处、天花板；高光承载物：柜台玻璃、铜铃
## 时段变体
- 雨夜（S03）：上述
- 晴天上午（S01）：窗光为主，5600K，台灯关
## 时代锁
2000 年代中国南方城市；可出现：老式收银机、搪瓷杯、手写价签；不可出现：智能手机支付码、LED 灯带
## 参考图要求（交 Image 2.5 资产提示词大师编写提示词）
主图：无人；从店门内侧一角、站立视线高度看全景，柜台、台灯、窗、书架、店门都入画；精确数量（一张柜台、一盏台灯）。
多视角：4 宫格（俯拍基准 / 正向 / 左侧 / 右侧），以主图为唯一依据推出。
站位示意图：S03 需要（2 人：林砚青色、周叙橙色）。
## 禁继承说明（给编译师）
只取空间、材质与光源位置；不作首帧，不继承构图、角度与调色。
```

**生图规则**：主图无人、一套光、锚点物齐全；其他角度一律从主图推出 4/6 宫格多视角（见《圣经》3.4 与 `crew/19-image25-prompt-master/SKILL.md` 3.2），不用视频截帧或白模取角度。多人场景另出站位示意图（3.3 节）。

## 产出 2：空间地图 GEO（写进 `06-场景圣经.md` 的每场小节）

**只写地方，不写人，不写动作。同场所有生成逐字粘贴。**

```
空间地图（本场所有镜头锁定）：
— 店门：画左前景，门上铜铃。
— 柜台：画右中景，L 形，长边与镜头轴线平行，距店门约 4 米。
— 绿罩台灯：柜台左端。
— 格子窗：后墙正中，窗外雨巷。
— 书架：整面左墙。
— 180° 轴线：店门与柜台之间的连线；摄影机始终在书架一侧，绝不越过柜台。
— 主光：台灯暖光来自画右；窗外冷光来自后方。
```
规则：左右以镜头为准；位置用锚点 + 米；写明机位侧和不可越过的线；静态对白给"房间一角"而不是整个房间。

## 产出 3：道具护照 `assets/props/<道具>/护照.md`

```
@prop_铜钥匙 ｜ 形制：老式单齿铜钥匙，约 6 厘米，钥匙柄有一个小孔穿着褪色的红绳 ｜ 材质：黄铜，边缘被磨亮 ｜
尺度参照：放在掌心约占掌心一半 ｜ 归属：S01–S03 属于林砚，S03 结尾起属于柜台 ｜ 状态变体：无 ｜
戏剧功能：两人关系的物化 ｜ 计数：全片只有一把，绝不出现第二把
```
叙事道具出**道具状态单图**（16:9 灰底，同一道具的 2–3 个状态并排，如关闭/打开、完整/破损，写清内部物件数量），由 Image 2.5 资产提示词大师编写提示词。

**道具操作机制（本岗位同时担任道具统筹）**：凡是镜头里会被手操作的道具，护照里加一栏"操作机制"，否则模型会出现"手在动、东西不动"的翻车：
```
操作机制：
- 开锁：钥匙齿朝下插入锁孔 → 顺时针转半圈 → 锁舌缩回 → 门向内打开约 30°
- 放下：钥匙从掌心滑到台面，发出一声轻响，平躺不滑动，红绳搭在玻璃上
状态变化表：S01 在林砚开衫口袋 → S03 第 18 秒放到柜台边缘 → 此后留在柜台
```
写法：手的动作 → 道具的结构如何响应 → 道具的结果状态。交给分镜师与编译师逐字使用。

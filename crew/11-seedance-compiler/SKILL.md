# Seedance 编译师 · SKILL

先读 `SOUL.md`。本技能的唯一知识权威是 `docs/02-Seedance2.5提示词圣经.md`，每次工作前读一遍相关章节。

## 输入（缺一不可，缺了退回对应岗位）

| 输入 | 来自 |
|---|---|

## 工作流

### 第 1 步 · 资产门
列出本条生成里出现的每个角色、状态变体、场景、道具。逐个对照 `registry.md`：全部 `locked` 才继续。有 `draft` → 停止，告诉总制片人哪个资产阻塞了哪条生成。不得用基础资产冒充状态变体。

### 第 2 步 · 选模式
按《圣经》1.3 选**一个**主模式 + 若干专项能力。两个主模式都说得通且会写出不同提示词时，问用户一个问题。

### 第 3 步 · 素材预检
数素材：图片 ≤30、视频 ≤10 且合计 ≤30 秒、音频 ≤10 且合计 ≤30 秒、总数 ≤50。超出稳定区间（图片主体 >8、视频/音频主体 >5）时标风险并给简化方案。工厂上限：参考图 ≤8、参考视频 ≤2、同框追踪角色 ≤3。

### 第 4 步 · 素材接线单
```
| 标签 | 文件 | 定义对象 | 采用属性 | 保真等级 | 禁继承 | 生效时间 |
```
标签写法严格照抄用户界面（即梦中文：`@图片1`；Dreamina：`@Image 1`）。上传顺序 = 标签编号。

### 第 5 步 · 容量核算（在写字之前算）
- 时长：时间段连续、无重叠、总和 = 时长；表演镜头 ≥ 2.5 秒；插入/冲击镜头可 0.3–1.5 秒但只能有一个可见事件；单个看/回头/拿放 1–2.5 秒；一句短台词 2–4 秒；超 4 秒的镜头必须有持续表演或空间揭示。
- 台词：按 3–5 汉字/秒，再扣反应和停顿。超容量 → **退回分镜师/编剧**，提出"砍哪句"或"拆条"两个方案，不擅自删台词。
- 活的种类：物理与表演都重 → 建议拆条。
- **复杂度预算**：按 `docs/06-一次成片方法论.md` 第二节杠杆 4 的表打分。任何一项红色 → 不编译，退回分镜师拆条或简化，并说明是哪一项超了。
- **控制手段**：检查本条有没有该有的图：角色设定图、场景图、道具图；动作复杂或构图关键时要求分镜师补**首帧图**；多镜头顺序要锁死时要求补关键帧或故事板。缺图时宁可先补图（便宜），也不要靠文字硬撑（贵）。

### 第 6 步 · 编译十二段
严格按《圣经》第四节骨架。另外三处社区验证过的加固写法（见 `docs/06` 第四至七节）：
- 【场景上下文】第一句写完整梗概 + 边界（"没有多余情节"），第二句写**必演节拍清单**："共 5 个镜头，必须按顺序全部出现；第 23 秒之后属于镜头 5，影片结束在镜头 5。"
- 【参考映射】写**冲突优先级**："站位、光线、场景冲突时以首帧 @图片X 为准；脸与服装以设定图 @图片Y 为准。"
- 【时间轴】每个镜头起一个短标题；需要时每镜单独附一行声音；有变速就在末尾附"变速清单"，没有就写"全片正常速度，无慢动作"。

各段的来源与规则：

| 段 | 来源 | 编译规则 |
|---|---|---|
| 【参考映射】 | 接线单 + 《资产提示词总册》第四节 | 每份素材的引用语**从总册逐字复制**（三视图：脸只从右侧大头像取，模糊椭圆不是脸；宫格：只取空间不作首帧；站位图：只取位置并附颜色↔角色对应表，颜色线稿标签不入画）；多人场景加参考优先级句 |
| 【场景上下文】 | 镜头卡 + 导演阐述 | 一句话主事件；**人数锁**放第一句 |
| 【空间地图】 | 场景圣经 GEO | **逐字粘贴**，同场每条一致 |
| 【首帧与站位】 | 分镜首帧 | 人物已在位、已在状态中；道具在谁手里 |
| 【角色锚点】 | 角色护照 | 名字 + 描述锁**逐字复制**；正文后续只用"名字+一个可见标记" |
| 【光学与摄影机】 | 影像圣经 + 镜头卡 | 视场角只用离散锚点；机位高度、支撑、主运镜、起止构图；"段内焦段不漂移" |
| 【时间轴】 | 镜头卡 | 每段：起始状态 → 一个主事件 → 结束状态；一拍 ≤ 3 句；一镜到底不写"切至"；多镜头写切点理由 |
| 【表演】 | 表演母本的本场改写 | 目标/隐藏/身体节奏/可见习惯/段内变化；眼神任务；微生命规则；情绪交给上半脸 |
| 【物理】 | 镜头卡动作 | 因果链；状态累积；招式名+意图，不写关节角度 |
| 【光照与色彩】 | 影像圣经 | 真实光源、方向、色温 K、60:30:10 |
| 【声音】 | 声音圣经 | 语种声明 → 现场声清单 → 对白 `{}`（音色锁逐字）→ 抑制句（不放进 `()`）→ "只说引号内台词，其他人闭口" |
| 【肯定约束】 | 各岗位风险 | 禁止改写为肯定；计数类用"先计数再禁止"；一条本镜失败判据 |

### 第 6.2 步 · 出 A / B 两个版本（`docs/09` 第 3.3 节）
先写 A 预演版：结构照预演（时间轴每行"同预演 X–Y 秒"，切点清单与预演一致）。再由 A 派生 B 无预演版：删掉 @视频1 职责句和所有"预演"字样，把预演承担的结构写成文字——每镜机位高度、离人物的米数、起止构图里人物占画高几分之几、切点清单；第 24 条触发的条加一张首帧图（同时在资产文档里加这张图）。两个版本的镜头数、切点、台词、声音、角色锁、空间地图逐字一致。最后写一行 `**推荐**：A 版 / B 版（理由）`。

### 第 6.5 步 · 五道内部编译关（一个作者，五个视角逐一过）
提示词只由编译师一人写成完整整体；但写完后必须换五个视角各过一遍，每一关只看自己的维度，发现问题回到对应段修改：

| 关 | 视角 | 只检查 | 上游依据 |
|---|---|---|---|
| 1 时间轴与节奏 | 剪辑师 | 时间码连续、总长、必演节拍清单、镜头标题、每段结束状态、变速声明、结尾剪辑指令 | 导演时间建筑、镜头卡 |
| 2 摄影、调度与表演 | 摄影指导 + 文戏/武戏导演 + 表演指导 | 每段一个视场角一个主运镜、起止构图、双重反差；目标/隐藏/眼神任务/手上的事、情绪累积、唇部写法 | 影像圣经、表演改写 |
| 3 参考与连续性 | 资产主管 + 场记 | 接线单与登记表一致、职责合同与禁继承、冲突优先级、描述锁/空间地图/音色锁逐字、入口状态 | registry、护照、账本 |
| 4 台词、声音与特效 | 台词对白导演 + 声音导演 + VFX 导演 | 台词逐字、每句时间与说话人、话轮、口型约束、语种声明；声音策略唯一、括号语法、逐镜声音行、跨条声音桥；特效七要素、颜色纪律、尺度锁；动作五步因果、损坏继承 | 声音圣经、VFX/动作设计 |
| 5 任务与参数 | 平台适配 | 主模式、时长、画幅、分辨率、音频开关、首尾帧画幅一致、素材数量与规格、标签写法与界面一致；这些参数只写在界面参数区，不进正文 | 立项书、资产主管预检 |

每关在编译说明里留一行"已过 / 改了什么"。

### 第 7 步 · 自检
先跑机检：`python3 tools/prompt_lint.py <提示词文件> --duration <秒>`（字符数、年龄词、淡出、平台参数混入、时间段连续与总长、人数锁、音乐抑制位置、正文标签、台词容量）。机检 FAIL 必须修完。再人工跑《圣经》第十节"提交前十六问"中机检覆盖不到的部分。>5000 字符按《圣经》第四节的删减顺序压缩。

### 第 8 步 · 交付
写入 `10-提示词/<场号>-<条号>-v<N>.md`，格式：

```markdown
# S01-G1 v1 ｜ 状态：compiled（未生成）
## 界面参数
模式：全能参考 ｜ 时长：30 秒 ｜ 画幅：2.39:1→界面选 21:9 ｜ 分辨率：720p ｜ 音频：开
## 素材接线单
（表格，上传顺序即编号）
## 提示词（复制此代码块）
​```text
……
​```
字符数：N / 5000
## 一次成片签字单
结构类型 / 复杂度（绿黄红及各项数值）/ 控制手段（用了哪些图）/ 最可能失败的点 / 若失败只改哪一行 / 是否建议低清先验
## 编译说明（不进模型）
- 拆条/取舍理由、已知风险、本条使用的护照版本号
```
复杂度为黄色时，签字单必须写明降风险的替代方案（例如"若镜头 4 翻车，改用关键帧参考"），交给总制片人与用户一起决定是否先低清验证。

### 超过 30 秒的项目
按 `docs/07-30秒以上长片衔接.md` 选方法（分镜拼接 / 关键帧续写 / 原生延长 / 故事板预览）。续写段必须有【续写起点】；角色块、画风块与上一段**逐字一致**；每段时间码从 0 起算；接缝策略（停在动作中途 or 停在稳定帧）在编译说明里写明。模板：`templates/长片续写段模板.md`。

## 专项模式速查

| 模式 | 必写 | 致命错误 |
|---|---|---|
| 视频延长 | 方向（原片之前/之后）、新增时长、"原视频不变，本提示只作用于新增 N 秒"、承接边界帧的动作/朝向/镜头速度/光/声 | "向前续写"这类歧义词；"然后接上原视频"（会提前泄漏后面的元素） |
| 视频编辑 | 唯一母版 + 编辑范围（标注/位置/对象）+ 操作（加/删/替换/改）+ 生效时间 + 完整保留清单；替换主体要写"继承原主体的时间、路径、遮挡、出画" | 没有保留清单；"改一下这个" |
| 首尾帧 | 每张图一句：`@图片1 是首帧，定义开场构图、站位、姿势、道具状态、机位朝向`；中间写一个连续动作 | `@图片1和2分别是首尾帧`（合并句）；首尾帧画幅不一致 |
| 多关键帧 | `按顺序使用 @图片1 至 @图片N 作为关键帧`，逐张写关键状态 | 把关键帧拼成一张图 |
| 多宫格分镜 | "每一格是一个完整镜头，不是独立人物或场景"；逐格写时间/构图/动作/运镜；角色另给参考图 | 让模型照抄格子线稿与编号 |
| 白模粗模 | 声明粗模，映射每个灰模到最终主体，借运动/机位/位置/节奏；禁继承灰模材质、视口背景、坐标轴、轨迹线、相机锥体 | 只写"参考白模" |
| 白模精模 | 渲染指令 + 材质 + 环境 + 光 | 重新描述动作（会和白模打架） |
| 无缝转场 | 两段原片都不改；连接物的形状/位置/大小/方向/速度/运动趋势锁定；触发动作 → 视觉变换 → 到达状态 | 没有连接物 |
| 绿幕合成 | 前景源、背景板、透视、尺度、接地、阴影、光向、溢色、运动模糊 | 漂浮脚、贴片光 |
| 音色绑定 | 角色 + 时间 + 引号台词 + 音色参考 + 保留的特质 + 不继承底噪 | "使用 @音频1" |

## 修订模式（审片退回后）

1. 读审片记录：时间点、维度、现象、怀疑的控制输入。
2. 分类故障层（身份/动作/运镜/构图/连续性/光/声音/文字），**只修那一层**。
3. **只改一行**；其余逐字不动；版本号 +1；旧版本保留。
4. 输出**完整替换稿**，绝不在提示词里写"不要之前的 X"。
5. 在 `logs/generation-log.md` 追加一行。
6. 同一缺陷 2 次不变 → 改结构；10–15 版不成 → 退回分镜师简化镜头。

## 完成标准

- 文件已写入，状态 `compiled`；字符数 ≤ 5000；十六问全过。
- 交场记做连续性与台词完整性审核，交合规官做合规审，交导演签字。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 每家按官方格式写（docs/13），白模只走参考入口。
- 提示词写画面里看得见的东西，不写形容词堆砌；约束写成肯定句。
- 高光镜头的描述写得最具体：光的方向、材质、运动的起止、声音的瞬间。

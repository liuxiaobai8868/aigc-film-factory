# 审片质检员 · SKILL

先读 `SOUL.md`、`docs/04-质检标准.md`。

## 流程

1. **准备**：拿到视频文件、对应提示词版本、接线单、镜头卡、角色参考图。
2. **观看**：至少完整看两遍（一遍看戏、一遍看技术）；能抽帧就抽帧（如 `ffmpeg -i in.mp4 -vf fps=2 frames/%03d.png`）逐帧检查脸、手、文字、接缝。
3. **打分**：按 `04-质检标准.md` 第二节 D1–D8，0/1/2 分，加权满分 24。D3 表演请表演指导打、D7 请台词对白导演和声音导演各打一次取低分、D4 请场记打；我负责其余维度、汇总和判决。精简模式下我一人打全部维度。
4. **判决**：≥20 且 D1/D2/D3 无 0 → 入选；15–19 → 局部可用/局部编辑；<15 或 D2=0 → 拒绝。
5. **缺陷记录**（每个 0 或 1 分）：

```markdown
| 时间 | 维度 | 现象 | 怀疑的控制输入 | 修法（一条） |
| 0:13 | D2 | 周叙眼镜消失 | 护照描述锁未提眼镜，参考图里眼镜不明显 | 护照升 v2 加"细金属框圆眼镜"，重压测 |
| 0:19 | D8 | 钥匙出现两把 | 无计数锁 | 【肯定约束】加"画面中只有一把铜钥匙，绝不出现第二把" |
```

6. **停止规则**：同一缺陷连续两次不变 → 通知编译师改结构；累计 10–15 版 → 退回分镜师简化；单场预算过半 → 通知总制片人。
7. **记录**：写 `reviews/审片-<条号>-v<N>.md`，在 `logs/generation-log.md` 追加一行；入选文件复制到 `selects/<场号>/` 并按条号命名。

## 成片质检（门9）
按 `04-质检标准.md` 第四节逐项检查，输出成片质检报告。

# 剧本医生 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`。

## 审核维度（逐项打分 1–5，并列问题）

| 维度 | 检查 |
|---|---|
| 1 结构 | 主线清楚；激励事件及时；中点/危机/高潮成立；每场因果相连，删一场后链条断不断 |
| 2 场景发动机 | 每场目标/阻碍/策略/反转/价值翻转齐全 |
| 3 人物 | 主角主动（推动而不是被推动）；对手有正当性；配角有自己的策略；人物行为符合已建立的设定 |
| 4 对白 | 逐句评：功能性（推动行动/揭示人物/制造冲突）与情绪性；<5 分删，5–7 分重写；有无解释性对白、车轱辘话、明说情绪；人物口气可区分；**像不像人说的**（crew/23 五条）：台词前有没有手上的动作、长句有没有标点呼吸、有没有回问一个词、难出口的话有没有变小声再重说、关键句有没有决定性动作——一场对白戏一条都没有，判重写 |
| 5 节奏与钩子 | 开场第一拍能否独立成钩；每场结尾留下追看理由；短剧：每集钩子与付费卡点 |
| 6 视觉化 | 情绪是否落在动作/物件/空间上；VO 是否必要 |
| 7 可生成性 | 每场台词 ≤ 90 字/30 秒；同框追踪 ≤ 3 人；无镜像双人、无关键画面文字依赖、无超长连续复杂动作；场景数量与资产预算匹配 |
| 8 原创性 | 有无照搬已有作品的情节/角色/台词 |

## 规则
- 所有问题一次列全；按 P0/P1/P2 排序。
- 每条：定位 + 问题 + 为什么 + 处方（可给 1–2 个方向，不代写整段）。
- 业务审与合规审的意见由总制片人合并后一次性交编剧。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 用第三节 A–H 逐条审，F（等救主）一票否决。
- 找"可以删的"：删掉后故事不受影响的人物、台词、镜头，全删。

# 分镜师 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`、`docs/03-30秒电影化叙事法.md`。

## 输入
`04-导演阐述.md`（本场时间建筑与视觉论点）、`05-影像圣经.md`、`06-场景圣经.md`（空间地图）、角色护照、`07-表演母本.md`、`03-剧本.md` 本场原文。

## 步骤

### 1. 事实与状态锁
从剧本抽出本场：在场角色、每句台词（原文，不改）、道具与归属、入场状态（伤、湿、服装、情绪余波）、出场状态。

### 2. 节拍 → 镜头
先列节拍（压力转换点），再给每个节拍分配镜头；每镜回答"新增了什么信息"。时长预算：
- 单一看向/回头/拿放/即时反应：1–2.5 秒
- 一句短台词或中等动作：2–4 秒
- 超过 4 秒：必须有持续表演、走位、空间揭示或两个以上关联的可见变化
- 表演镜头不少于 2.5 秒；插入/冲击镜头（枪口一闪、杯子落地）可 0.3–1.5 秒，只能有一个可见事件
- 剧情对白戏 30 秒内 4–7 镜；蒙太奇或动作段落可以更多，但每镜只做一件极简单的事、几乎不带台词；镜头数在场与场之间刻意不均匀

### 3. 镜头卡（每镜一张）

```markdown
#### S03-G1 · 镜头 3（11–17 秒）
- 节拍功能：他听——本场最强一拍，他停下手上的事
- 新增信息：他已经明白她的来意
- 景别/视场角：近景 18° → 结束于特写（轨道极慢推近，段内视场角不变，推近靠机身前移）
- 机位：柜台外侧、与他眼睛同高、书架一侧（不越轴）
- 运镜：目的=逼近他的沉默；起=近景腰上；主运镜=轨道前推；速度=匀慢；止=特写眉眼；衔接=硬切道具特写
- 入口状态：周叙站在柜台后，右手拿着抹布正在擦柜台玻璃，左手扶着台面
- 动作：她的话音落下后半秒，抹布停在玻璃上；他没有抬头，视线落在她放在台面边缘的手上；一次慢眨
- 出口状态：抹布仍压在玻璃上不动，他的视线停在台面那只手上
- 视线：画左下（她的手的位置）
- 道具：抹布在周叙右手；钥匙仍在林砚手里（画外）
- 光：台灯暖光从画右打在他半边脸，另一半在暗部
- 声音：雨声持续；她的上一句台词尾音延续到本镜开头（L-cut）
- 台词：无
- 风险：手部与玻璃接触易穿模 → 首帧固定抹布已压在玻璃上
```

### 4. 生成条首帧/关键帧设计
按连续性风险选择控制方式：
| 风险 | 方式 |
|---|---|
| 单一稳定构图里的简单动作 | 只要首帧 |
| 起止状态都关键（站位/道具交接） | 首帧 + 尾帧 |
| 多镜头顺序与构图都要锁 | 多宫格分镜图（每格一镜）或多关键帧（独立图，比拼图稳） |
| 复杂调度/运镜路径/打斗 | Blender 白模预演视频（粗模），交编译师作运动参考 |

首帧提示词规则：使用角色与场景已锁定的参考图；画面里人物已在位、在状态中；与本片画幅一致；不出现文字；光与影像圣经一致。

多宫格分镜图：一页 4–6 格，每格标顺序（编号写在格外或用边框颜色区分，告诉编译师禁继承编号文字），格内构图即该镜构图。

**首帧图是降抽卡的第一手段**（`docs/06` 杠杆 2）：凡是构图关键、站位复杂、光线特殊、或复杂度为黄色的生成条，必须先出首帧图，用生图模型改到满意再交编译师。生图比生视频便宜得多。

### 4.4 汇总各分场导演的设计（P6 同步进行）
镜头卡要合并：文戏导演的调度与覆盖方案（文戏场）、武戏导演的动作设计（动作场）、VFX 导演的特效设计（特效场）、台词对白导演的台词时间表、声音导演的逐镜声音行。四者时间不一致时，以台词时间表与覆盖方案对齐为先，冲突交总导演裁决。

**站位示意图在本阶段出**：调度定下来之后，多人场景向 Image 2.5 资产提示词大师提出站位示意图需求（颜色↔角色对应、每人位置、关键道具位置），出图后交资产主管登记。不在资产阶段提前出。

### 4.5 故事板预览板（全片或一集，生成任何视频前）
按 `docs/07-30秒以上长片衔接.md` 第五节版面，用生图模型出一张横版故事板：每场一格（首帧 + 尾帧小图、镜头/焦段→运动、剧情一句、台词/旁白），底栏放主色卡色值、字体、音乐与音效、交付规格。交导演审完再进入编译。打斗和多人场面不用这种方式，改用白模预演或关键帧。

### 4.6 续写关键帧（多条连续生成之间）
上一条入选后，从中截取下一条需要的参考帧（`docs/07` 第三节）：人物站位全景、主配角正反打、场景图没有的侧面、资产图没有的道具细节、含关键剧情的尾帧（尾帧只是手部特写之类细节就不截）。截图只负责站位、空间和状态，脸仍然从角色设定图取。截图存 `assets/keyframes/<条号>/`，并在接线单里写明用途。

### 5. 自检
- [ ] 每镜新增信息；特写改变判断
- [ ] 入口=上一镜出口
- [ ] 一镜一个主运镜、一个视场角；切镜双重反差
- [ ] 轴线、视线、运动方向连续
- [ ] 台词逐句与剧本一致，时间装得下（3–5 字/秒 + 反应）
- [ ] 无出画再入画、无反射主镜、无画面文字、追踪角色 ≤3
- [ ] 每条生成的总时长 = 镜头时长之和，≤30 秒

### 6. 交付
写入 `09-分镜/<场号>.md`：生成条划分表 + 镜头卡 + 首帧/关键帧/宫格提示词 + （可选）白模说明。交导演审（门6）。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- **张力**：镜头时长有长有短（最长 ≥ 最短 1.5 倍），高光前用短镜头加速；相邻两镜景别和角度都要变；转折镜头给 `move`（推近、横移揭示、手持）并写 `why`；整条要静就写 `stillness` 并安排爆发点。
- 镜头语法完整：建立、关系、反应、插入、转场；每条至少三种景别。
- 切点切在动作和情绪的拐点上；硬切要带来新信息。
- 在 `分镜.json` 里标出每条的价值翻转和视听高光镜头。

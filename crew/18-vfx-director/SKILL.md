# VFX 导演 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`。只在标注了特效的场次启用。

## 产出：`09-分镜/<场号>-VFX设计.md`

### 1. 规则卡（全片每种超自然能力一张）
```
能力：雷电剑
来源：剑身导电，只在兵器接触、发力或导电接触时增强
边界：不能远程放电；电弧只沿金属与人体传导
代价：每次强放电后持剑手臂发麻，动作慢半拍
外观：实体钢剑，蓝白电弧贴着刃口游走，不变成宽大的光剑
颜色纪律：电弧蓝白；环境、火焰保持本色，不把画面染蓝
```

### 2. 特效事件表（每条生成）
```
| 时间 | 事件 | 触发 | 源点 | 方向/尺度/速度 | 介质反馈 | 环境照明 | 衰减与残留 |
| 12–15s | 三条锁链同时熄灭并崩脱 | 剑刺穿锁印 | 王座底座 | 沿锁链向城外，回弹先掠过平台 | 铁屑、碎石沿受力方向飞 | 红光熄灭，平台变暗 | 链条拖擦痕留在地面 |
```
每条生成主特效事件 ≤1（复杂度预算）；超出 → 建议拆条。

**规则档和强度档**（2026-11-07，来自《列阵》）：先定规则档，再定视觉。
- 规则档：R0 人体写实 / R1 超人体（快、硬、跳得高）/ R2 术法 / R3 规则级（改写时间、空间、因果）。
- 强度档：T0 贴身微光 / T1 局部 / T2 区域 / T3 场面级。**T3 全片最多一次**，留给高潮。
- 特效的方向就是力的方向，尺度就是力量档，按衰减曲线掉下去。
- **能量只用一个主色加一个辅色**，能量色和环境色温至少差 1500K（暖环境配冷能量，或反过来），否则特效会糊进背景。
- 特效颜色要能在角色设定里找到归属（这个人的"劲气颜色"），不按招式库的原配色乱换。
- **技能三拍和代价**：起手（可以被打断）→ 释放（接触点可见）→ 余波（**施法者**喘、抖、跪、流鼻血）。没有可见代价的技能就是许愿机。

### 2.5 大招的戏剧结构（一次大招、必杀技、法术决战）

七要素管一个特效的物理，大招还要有**戏剧结构**。六层，至少成立四层：
1. **起势**：身体和环境先有反应（衣摆、尘土、光线被吸过去），可以被打断；
2. **聚能**：空间先失真、失声、失重，能量往一个点收；
3. **主体形态**：不要总是球和光柱——法相、神禽凶兽、剑阵剑河、火莲、冰镜、古印、大钟、天碑、扇面冲击波、环状震荡圈、漩涡吞噬核；
4. **清场**：扫掉杂兵或障碍；
5. **首领终结**：**比清场至少升级一项**——体量、速度、材质、形态、镜头或结果；
6. **余波**：环境遗留（焦痕、冰封、塌陷）和施法者的代价。

**反同质化公式**：主属性 + 设计母题 + 主体形态 + 清场方式 + 终结方式 + 环境遗留，六项至少换三项，才算一个新的大招。

**去色测试**：把颜色去掉，这个大招还有独特的结构吗？只换颜色、不换结构的，重新设计；所有属性都写成"聚球 → 发射 → 爆炸"的，重新设计。

### 3. 尺度锁（有巨物时）
写尺度对比 + 人在画面里当比例尺 + 失败判据：
`巨兽高度约等于五层楼；画面中人物只到它的脚踝；若巨兽看起来像一个大个子的人或能和人轻松同框 = 失败镜头。`

### 4. 实现路线
| 情况 | 路线 |
|---|---|
| 简单光效、粒子、天气 | 模型直接生成，写七要素 |
| 有明确运动轨迹的特效 | 参考视频或白模（交资产主管登记） |
| 变身、时空转场 | 一镜到底 + 变换规则（每一步用延续的材质或形状衔接，人物不溶解、不复制、不变尺度） |
| 文字、界面、精确合成 | 后期，不进生成 |
| 两段之间的魔法转场 | 视频编辑的"无缝转场"模式，锁定连接物 |

## 审核
审镜头卡与提示词：七要素齐全；有触发；颜色纪律句存在；尺度锁与比例尺；每条 ≤1 个主特效；接触点和脸没有被特效遮住（特效从接触点向外长，中心留空）；没有空词；T3 全片不超过一次；大招过去色测试；施法者有代价。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- **落到数据**：每个特效镜头写 `vfx` 七要素（源点、方向、尺度、速度、介质反馈、环境照明、衰减残留）；特效词出现而没写会被校验器拦（docs/19）。
- 特效服务故事：每个特效有源头、方向、尺度、介质反馈、照明、残留，并且有代价。
- 特效的颜色属于世界的色彩纪律，不乱加光效。

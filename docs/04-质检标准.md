# 质检标准

> 三层质检：**提示词质检**（生成前，免费）→ **单条审片**（生成后）→ **成片质检**（交付前）。
> 合并自 goodcase.ai 7 维审片表、spark-video 6 轴自动审片、95 分钟长片的接收标准、manju-laoli 投喂六道闸门。

---

## 一、提示词质检（P8，生成前）

逐项 PASS/FAIL，任何 FAIL 不得提交。

| # | 闸门 | 检查 |
|---|---|---|
| G1 | 模式与参数 | 主模式正确；时长/画幅/分辨率在界面设置、不在正文 |
| G2 | 素材合同 | 每份素材有职责+保真等级+禁继承；标签与上传顺序一致；本条不在场的主体无标签 |
| G3 | 资产锁定 | 所有出场资产在 registry 为 `locked`；描述锁、空间地图、音色锁与源文件**逐字一致** |
| G4 | 人数与空间 | 有人数锁、空间地图、轴线、首帧站位；切镜后重申站位 |
| G5 | 时间 | 时间段连续不重叠、总和=时长；每段一个主事件 + 结束状态 |
| G6 | 摄影 | 每段一个视场角、一个主运镜、起止构图；切镜满足双重反差 |
| G7 | 台词完整性 | 与剧本/分镜逐句对照，不丢句、不改词；台词量在容量内；说话人明确；其他人闭口 |
| G8 | 表演 | 情绪全部为可见行为；有眼神任务；泪/笑/怒有累积；无唇部压缩词 |
| G9 | 物理 | 动作因果链完整、顺序正确；状态累积 |
| G10 | 声音 | 一种声音策略；括号语法正确；抑制不在 `()` 里 |
| G11 | 风险词 | 无年龄词、无反射主镜、无关键文字、无"淡出"、无否定陷阱 |
| G12 | 长度 | ≤ 5000 字符 |

## 二、单条审片（P9，生成后）

**看视频本身，不看提示词。** 每一项 0/1/2 分（2=通过，1=大体可用有可见瑕疵，0=失败）。

**分维度打分**：D3 表演由表演指导打分，D7 由台词对白导演和声音导演各打一次取低分，D4 空间连续由场记打分；其余由审片质检员打分，并由审片质检员汇总、下判决。精简模式下由审片质检员一人打全部维度。

| 维度 | 观察点 | 权重 |
|---|---|---|
| D1 叙事完成 | 每个规定节拍都发生了一次、顺序正确、时长占比合理；结束帧可接 | ×2 |
| D2 身份锁 | 脸、发型、服装、体格、道具外形跨切镜不变；无双胞胎 | ×2 |
| D3 表演 | 目标可读、反应链成立、眼睛活、无表情包切换、无塑料皮肤 | ×2 |
| D4 空间连续 | 站位、朝向、视线、轴线、门把手位置、运动方向不乱 | ×1.5 |
| D5 运动与物理 | 动作完成；肢体/物体不瞬移不融合不增减；受力合理 | ×1.5 |
| D6 摄影 | 运镜按设计、构图有中心、光有来源、色温统一 | ×1 |
| D7 台词与声音 | 台词与口型：只说规定台词、口型对位、无他人嘟囔、话轮自然、口音一致（台词对白导演打分）；声音：现场声对位、声音节奏成立、无多余 BGM 与字幕、跨缝连续（声音导演打分）；本项取两人中的较低分 | ×1 |
| D8 画面卫生 | 无乱码文字、水印、Logo、多余手指、牙齿/手部伪影、闪烁 | ×1 |

**满分 24。判决：**
- **≥ 20 且 D1/D2/D3 都不为 0** → 入选 `selects/`
- **15–19** → 可作为素材局部使用（取背景或某一段），或局部编辑修复
- **< 15 或 D2=0** → 拒绝，进入修复循环

每个 0 或 1 都要记录：**时间点 + 现象 + 可能的控制输入 + 一条有边界的修法**。

## 三、修复循环

```
拒绝 → 故障分类（身份/动作/运镜/构图/连续性/光/声音/文字）
     → 定位控制输入（哪份素材？哪一段时间轴？哪一句？）
     → 只改一行 → 版本号 +1 → 重新生成 → 重新打分 → 记日志
```

停止规则阶梯：
1. 同一缺陷连续 2 次重抽不变 → 停止抽卡，改提示词结构。
2. 一个镜头累计 10–15 个版本不成 → 退回分镜师：拆镜 / 删动作 / 换角度。
3. 单场花费过半预算仍不成 → 总制片人介入，与用户商量降级方案。

日志表 `logs/generation-log.md`：

```
| 条号 | 版本 | 改了什么（只一行） | 平台/模式/参数 | 得分 D1–D8 | 判决 | 文件 |
```

## 四、成片质检（P10，交付前）

| 维度 | 检查 |
|---|---|
| 叙事 | 每场戏核成立；集尾钩子/结尾落点成立 |
| 连续性 | 跨场景人物外观、伤妆湿度、道具、时间光线连贯 |
| 剪辑 | 切点有理由；节奏有变化；无跳帧；接缝处情绪和声音跨缝 |
| 调色 | 全片色彩脚本统一；肤色稳定 |
| 声音 | 对白清晰；响度达标（短视频平台 -14 LUFS 左右，影院/长片按交付规范）；无爆音、无突然的底噪变化 |
| 字幕 | 与台词逐字一致；不遮挡关键画面；安全框 |
| 技术 | 分辨率、帧率、画幅、码率、时长、文件命名符合交付规格 |
| 合规 | 再过一遍合规清单 |

# 项目目录与文件契约

每个项目一个目录 `projects/<项目名>/`。所有岗位只读写自己负责的文件，下游只读上游。

```
projects/<项目名>/
├── production.json              # 总制片人维护：阶段状态、门禁记录、依赖、预算消耗
├── .agent-state.json            # 各岗位 agentId（同一集内 resume，跨集重置）
├── 00-立项书.md                  # 总制片人（含模式：完整/精简）
├── 00a-参考片研究书.md            # 风格参考总监（有参考导演/电影时）
├── 01-故事圣经.md                # 故事架构师
├── 02-分场表.md                  # 故事架构师
├── 03-剧本.md                    # 编剧（多集时：03-剧本/ep01.md …）
├── 04-导演阐述.md                # 总导演
├── 05-影像圣经.md                # 摄影指导
├── 06-场景圣经.md                # 美术指导（含每场空间地图 GEO）
├── 07-表演母本.md                # 表演指导
├── 08-声音圣经.md                # 声音导演
├── 08a-台词总表.md               # 台词对白导演（全片台词与逐场容量预审）
├── assets/
│   ├── registry.md              # 资产登记表：标签 | 类型 | 版本 | 状态 draft/locked | 文件
│   ├── characters/<角色>/护照.md + 参考图 + 压测/
│   ├── locations/<场景>/护照.md + 参考图
│   └── props/<道具>/护照.md + 参考图
├── 09-分镜/<场号>.md             # 分镜师：镜头卡 + 首帧/关键帧
│   ├── <场号>-文戏调度.md          # 文戏导演（文戏场）
│   ├── <场号>-动作设计.md          # 武戏导演（动作场）
│   ├── <场号>-VFX设计.md           # VFX 导演（特效场）
│   ├── <场号>-台词时间表.md        # 台词对白导演
│   └── <场号>-声音设计.md          # 声音导演
├── 10-提示词/<场号>-<条号>-v<N>.md # Seedance 编译师（旧版本保留）
├── reviews/                     # 剧本医生、场记、合规官、审片员的审核记录
├── logs/
│   ├── generation-log.md        # 每次生成一行
│   └── 平台差异.md               # 界面与《提示词圣经》不一致的记录
├── generations/<场号>/           # 原始生成（不剪）
├── selects/<场号>/               # 入选（剪辑只从这里取）
└── post/                        # 剪辑工程、调色、混音、字幕、交付文件
```

> 精简模式的合并文件结构见 `docs/08-精简模式.md` 第四节（剧本一份、制作圣经一份、分镜每场一份）。

## 命名约定

- 场号：`S01`、`S02`；生成条号：`S01-G1`、`S01-G2`（一场戏可能拆成多条生成）。
- 资产标签：`@角色名`、`@角色名_状态`、`@loc_场景名`、`@prop_道具名`。全项目一本字典，文档、提示词、界面里同一个名字。
- 提示词版本：`S01-G1-v3.md`，每次修改只改一行，旧版本不覆盖。

## 状态机

每条生成的状态：`planned → assets-ready → compiled → approved(门7) → submitted → generated → reviewed → selected / rejected`。
**永远不要把"提示词写好了"说成"视频做好了"。**

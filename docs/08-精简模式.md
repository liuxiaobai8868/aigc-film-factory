# 精简模式（30 秒 – 5 分钟）

> 适合：单条 30 秒短片、1–5 分钟的短片、广告、MV、单集短剧样片。
> 目标：岗位合并、文档合并、门禁合并，但**一次成片的保障一个都不减**——审核独立、资产对账、四签放行、付费前问你，这些和完整模式完全一样。
> 完整模式见 `docs/01-流水线总图.md`。

---

## 一、什么时候用精简模式

| 条件 | 精简 | 完整 |
|---|---|---|
| 总时长 | 30 秒 – 5 分钟 | 5 分钟以上、多集 |
| 生成条数（按每条 ≤30 秒） | 1 – 14 条左右 | 更多 |
| 主要角色 | ≤ 4 人 | 更多 |
| 场景 | ≤ 3 个 | 更多 |
| 动作/特效 | 无，或轻量（一两个动作镜头、一个特效） | 重动作、重特效段落 |

时长与条数的参考：30 秒 ≈ 1 条；1 分钟 ≈ 2–3 条；3 分钟 ≈ 6–8 条；5 分钟 ≈ 10–14 条（有剪辑点的拼接法，单条 20–30 秒）。

**升级到完整模式的信号**：超过 5 分钟；主要角色超过 4 人；有一整场重动作或重特效；要做连续剧。立项时总制片人按这张表建议，你决定。

## 二、精简模式的岗位（25 个岗位合并为 18 个席位）

| 席位 | 由谁担任 | 兼任的职责 |
|---|---|---|
| 1 | 总制片人 | 不变 |
| 2 | 风格参考总监 | 不变（有参考导演/电影时才启用） |
| 3 | **编剧** | **兼任故事架构师**：一次产出故事梗概、分场表和剧本 |
| 4 | 剧本医生（审） | 不变，不合并 |
| 5 | **总导演** | **兼任文戏导演**；轻量动作和特效也由总导演按武戏/VFX 导演的方法处理 |
| 6 | 摄影指导（兼灯光） | 不变 |
| 7 | **美术指导** | **兼任角色造型师**（场景、道具、角色护照一起出） |
| 8 | **表演指导** | **兼任台词对白导演**（台词时间表、话轮、口型约束） |
| 9 | 声音导演 | 不变 |
| 10 | Image 2.5 资产提示词大师 | 不变 |
| 11 | 多模态资产主管 | 不变，不合并 |
| 12 | 分镜师 | 不变 |
| 13 | Seedance 编译师 | 不变 |
| 14 | 场记（审） | 不变，不合并 |
| 15 | 提示词独立质检官（审） | 不变，不合并 |
| 16 | 合规官（审） | 不变，不合并 |
| 17 | 审片质检员（审） | 一人打全部审片维度 |
| 18 | **剪辑调色师** | **兼任后期声音与混音师**；门6 剪辑预审照做 |

有重动作或重特效时，单独启用武戏导演 / VFX 导演（不合并），其余仍按精简模式。

## 三、精简流程（7 步，6 道门）

```
L1 立项 + 参考研究 ─── 总制片人（+风格参考总监）── 立项书 + 参考片研究书 ───── [门A 用户确认]
L2 故事与剧本 ──────── 编剧 ── 梗概 + 分场表 + 剧本（一份文件）
                       ── 剧本医生 + 合规官一次审完 ────────────────────── [门B]
L3 制作圣经 ────────── 总导演牵头，摄影、美术、表演、声音并行各写一节
                       ── 合成一份《制作圣经》── 用户确认调性 ────────────── [门C]
L4 资产 ────────────── Image 2.5 大师《资产提示词总册》→ 出图 → 资产主管登记
                       → 角色压力测试 6/6 → 总导演签字 ─────────────────── [门D]
L5 分镜与调度 ──────── 分镜师牵头：总导演（文戏调度）+ 表演指导（台词时间表）
                       + 声音导演（逐镜声音）→ 镜头卡、首帧、站位图
                       ── 总导演 + 剪辑预审 ────────────────────────── [门E]
L6 编译与四签 ──────── 编译师 → 资产主管对账 → 场记 + 质检官 + 合规官 + 总导演 ─ [门F 四签]
L7 生成、审片、后期 ── 用户授权 → 生成 → 审片质检员 → 剪辑调色（兼混音）→ 交付
```

和完整模式相比：
- **门合并**：故事和剧本一起审（门B）；导演阐述和五份开发文件合成一份《制作圣经》一起确认（门C）。
- **压力测试**：角色从 10 次降到 6 次（2 个角度 × 本片 2 种主要光 + 2 张与搭档的双人图），全部通过才锁定。
- **不减的**：剧本独立审、资产对账、生成前四签、付费前问你、审片打分、只改一行的修复规则。

## 四、精简模式的文件（6 份主文件）

```
projects/<项目>/
├── 00-立项书.md               # 含模式：精简；参考清单
├── 00a-参考片研究书.md         # 可选
├── 01-剧本.md                 # 梗概 + 分场表 + 剧本，三节合一（编剧）
├── 02-制作圣经.md              # 一份文件分六节：
│                              #   导演阐述（总导演）/ 影像（摄影）/ 场景与道具 + 空间地图（美术）
│                              #   角色护照（美术）/ 表演母本 + 台词总表（表演）/ 声音圣经（声音导演）
├── assets/资产提示词总册.md     # Image 2.5 大师
├── assets/registry.md         # 资产主管
├── 03-分镜/<场号>.md           # 镜头卡 + 文戏调度 + 台词时间表 + 逐镜声音，合在一份
├── 04-提示词/<条号>-v<N>.md     # 编译师
├── reviews/ logs/ generations/ selects/ post/
```

《制作圣经》模板：`templates/制作圣经模板.md`。

## 五、各时长的典型做法

| 时长 | 生成条数 | 推荐结构 | 要点 |
|---|---|---|---|
| 30 秒 | 1 | 结构 A（一镜到底）或 B（五镜头） | 一条就是一场戏；首帧图几乎必做；台词 ≤60 字 |
| 1 分钟 | 2–3 | 每条一场，或一场拆两条 | 条与条之间用关键帧续写；第一条的最后 3 秒设计成交接帧 |
| 3 分钟 | 6–8 | 3–4 场 × 每场 1–2 条 | 先出故事板预览板审全片；每场固定一个空间地图 |
| 5 分钟 | 10–14 | 4–6 场 | 接近完整模式的上限；场景控制在 3 个以内，角色 ≤4 人，否则升级完整模式 |

## 六、总制片人如何执行精简模式

- 立项书写明"模式：精简"后，调度表按本文件第二节的席位分配；兼任岗位的 agent 同时读两个岗位的 SKILL（例如编剧读 `02-screenwriter` 和 `01-story-architect`）。
- 兼任岗位的产出仍然按原岗位的标准写，只是合进同一份文件。
- 审核岗位（剧本医生、场记、提示词质检官、合规官、审片质检员）和资产主管永远独立调用，不和生产岗位合并。
- 项目中途超出精简模式的边界（例如加到 6 个角色），总制片人提示你升级到完整模式，已完成的文件按完整模式的文件名拆分，不重做。

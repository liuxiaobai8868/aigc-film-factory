# 30 秒以上长片衔接

> 单次生成最多 30 秒。超过 30 秒的故事，难点有三个：剧情太长、分镜写不好；人物和场景一致性不可控；前后两段接不上（探路AI 的总结）。
> 本文合并了探路AI《如何生成30秒以上AI视频》的三种方法、社区一条 60 秒四段连续接力的中文案例（巨虫王座那条）、Giza 旅行者多步工作流，以及官方的视频延长规则。

---

## 一、四种方法怎么选

| 方法 | 原理 | 成本 | 适合 | 不适合 |
|---|---|---|---|---|
| **A 分镜拼接法** | 一场戏规划成 25–30 秒一条，多条剪在一起 | 低 | 有剪辑点的剧情片、短剧（**默认**） | 必须无缝的一镜到底 |
| **B 关键帧续写法** | 从上一条截关键帧当参考图，生成下一条 | 低 | 同一场景、同一组人的连续剧情 | — |
| **C 原生视频延长** | 用平台的"视频延长"从边界帧接着生成 | 高（按源视频计费，链条最多约 60 秒） | 必须完全无缝的连续动作 | 长链（越接越糊） |
| **D 故事板预览法** | 先出整张故事板图审稿，再按故事板锚图逐条生成 | 低 | 慢节奏、两个主角的剧情片和广告 | 打斗、人多 |

实际项目里经常组合：D 先审全片 → A 规划每条 → 条与条之间用 B 交接 → 只有少数必须无缝的地方用 C。

---

## 二、方法 A：分镜拼接法

1. 灵感 → 剧本大纲 → 分集 → 每集拆成若干场戏。
2. 每场戏规划为一条或几条 25–30 秒的生成（本工厂分场表 + 导演时间建筑已经覆盖）。
3. 每条按十二段式编译。
4. 剪辑接缝处用反应镜头、道具插入、声音桥（J/L-cut）过渡。

关键：每条生成的最后 3–4 秒做成**稳定的交接帧**（人物位置、视线、道具、光都清楚），下一条才能接得上。

## 三、方法 B：关键帧续写法（最省钱的连续性手段）

### 3.1 截哪些帧
从上一条入选视频里截图，作为下一条的参考图。按两段剧情怎么衔接来决定截哪些：

| 截什么 | 为什么 |
|---|---|
| **人物站位全景图** | 告诉下一条所有人在哪 |
| **主角、配角的正反打截图** | 下一条有对话时，两个方向的机位都有依据 |
| **场景图没覆盖到的侧面** | 防止下一条转到新角度时重新发明场景 |
| **资产图没覆盖到的道具、细节** | 中途出现的道具、损坏状态 |
| **含关键剧情信息的尾帧** | 下一条从这里开始；如果尾帧只是手部特写之类的细节，就不用截 |

截图的脸常常偏糊，所以**脸仍然从角色设定图取**，截图只负责站位、空间和状态。

### 3.2 续写提示词的结构
```text
延续 @图片1、@图片2 两张图的后续剧情，生成一段 20 秒、横屏的写实视频：【一句话剧情】。

【人物与物体对应】
画面共 8 人：A 在最前方；B 与搀扶他的 C 在后方；四名对手在最后方，姿态嚣张。
配角只作背景，不参与动作，不增加台词或单独的反应镜头。
从对手中指定一人（@图片5 中的纹身男）作为本段说话和受击的人，全程是同一个人；其他人站在他身后。

【视觉风格】
延续前段的写实电影质感、日光、色调与环境。（并写出本段的动作质感要求）

【资产锚点】
A 的脸：严格参考 @图片3（清晰面部图），锁定脸型、五官、发型；不要把截图里的面部模糊迁移到角色上。
A 的服装：参考 @图片4 正反面角色卡，锁定上衣、裙子、鞋；鞋在动作中不脱落。
B、C：参考 @图片6、@图片7。对手群：参考 @图片8。不增加重复面孔。

【时间轴】……
【声音】……
```
要点：**人物与物体对应**这一段写人数、前后位置、谁是本段主角、配角做什么不做什么；**资产锚点**这一段明确"截图负责站位，设定图负责脸和衣服"。

## 四、方法 C：原生视频延长 / 连续长镜头接力

### 4.1 官方规则
- 源视频 30 秒以内，单次延长 4–30 秒，一条链最多约 60 秒。超过就从原始资产重新起锚，不要延长"延长出来的视频"。
- 必须写清方向：新增片段在原片**之前**还是**之后**。
- 只描述新增区间；"原视频保持不变"。
- 先对齐边界帧，再写新内容。后延：从原片最后一帧接着动；前延：新片段必须**结束在**原片第一帧。

### 4.2 连续长镜头接力（四段 60 秒案例的写法）
这条社区案例把一个 60 秒的连续动作长镜头拆成 4 段 × 15 秒，结构值得照搬：

```
【参考绑定】每份素材管什么（动作节奏视频 / 主角脸 / 主角服装 / 每个对手 / 巨物尺度 / 盟友）
【全局真实系前缀】质感、主角锁、兵器形态、色彩纪律、空气粉尘、重量与接触阴影
【摄影、灯光与空间锁定】
  摄影：全片设计为连续运动长镜头，四段在同一动作状态接续，不出现可见剪辑；机位距离与高度；只在关键接触用不足半秒的减速
  灯光：天空主光 + 场内固定方向的火光；特效光随距离衰减
  空间：入口方向、推进轴线、每个对手的位置、后面会用到的桥和锁链——开场全部可见
【第一段｜0–15 秒：段标题】
  0–3 秒｜小标题：动作……
  ……
  段尾：她正在完成旋转，剑回到身侧；镜头绕到台阶方向。下一段从她落脚继续。
【第二段｜15–30 秒：段标题】
  续写起点：她旋踢后正在落脚；守卫头部偏转，长刀嵌在台阶里；先前倒地的人留在原地，不重置成站立状态；三条铁链仍绷紧。
  0–4 秒｜……（每段时间码从 0 重新起算）
……
【全片音频与负面约束】声音分层、连续性（双臂完整、不换脸、损坏继承、尺度稳定、不瞬移不复制）、画面禁区
```

四条硬规则：
1. **续写起点**：每一段开头写清上一段结束时每个人、每件东西的精确状态，并写"不重置"。
2. **段尾停在动作中途**（用于无缝长镜头）：停在"正在落脚""正在转身"，下一段从这个动作接着完成，接缝就藏在运动里。
   - 对比：**分镜拼接法**的段尾要停在**稳定画面**上，方便切。两种策略不要混。
3. **后面要用的东西开场就在**：巨物、锁链、桥在第一段第一帧就可见。
4. **每段时间码从 0 起算**，段的位置写在段标题里。

## 五、方法 D：故事板预览法

### 5.1 故事板图的版面（用生图模型出一张横版大图）
```
顶栏：片名 ｜ 总时长 · 画幅 · 色彩 ｜ 风格关键词（如：日系青春 × 怀旧 × 通透 × 纯净音效 × 旁白）
每场一格（8 场 = 2 行 × 4 格）：
  SCENE 01  场名  0.0–6.0s
  [首帧小图] [尾帧小图]
  镜头/焦段：35mm · 静止长镜头  →  运动：静止镜头
  剧情：一句话
  旁白/台词：一句
底栏：
  主色卡：5 个色块 + 色值（如 #8FA8B4 #F7F9FA #C1B6A9 #1C2841 #FFB7C5）
  字体：标题字体与字距
  音乐与音效：纯环境音与拟音（无 BGM）；窗帘摩擦、卡带咔嗒、海浪、风声；女声旁白，清澈羞涩
  交付：24fps ｜ 1920×1080 ｜ 胶片 LUT
```

### 5.2 流程
1. 生成故事板图，检查分镜错误（这一步只花一张图的钱）。
2. 以故事板为基础，生成一张"角色 + 场景"中近景图，作为身份与风格锚点。
3. 裁剪故事板，只保留色卡、声音等设定区，去掉分镜画面。
4. 生成视频：参考图 = 角色场景锚点图 + 设定区；提示词 = 基础设定 + 风格 + 本条画面描述 + 色卡。
5. 不适合打斗和多人场面。

## 六、跨条不漂移清单（每条续写都检查）

- [ ] 角色描述块与上一条**逐字一致**（复制，不重写）
- [ ] 画风/质感块与上一条逐字一致
- [ ] 脸从设定图取，截图只用于站位和空间
- [ ] 人物数量、谁在前谁在后、谁是本段主角写清
- [ ] 道具状态、伤、湿、损坏从上一条出口状态继承（场记账本）
- [ ] 后面要用的东西已经在画面里
- [ ] 接缝策略明确：停在动作中途（无缝）还是停在稳定帧（剪切）
- [ ] 下一条开头的声音接住上一条的最后一句或最后一个声音
- [ ] 时间码从 0 起算

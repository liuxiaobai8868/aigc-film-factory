# 流水线总图（完整模式）

> **完整模式，用户明确要求时才用**（默认模式见 docs/09、docs/18）。从一句创意到交付成片：12 个阶段、26 个岗位、9 道门禁。适合 5 分钟以上的短片、长片、连续剧。
> 30 秒到 5 分钟的项目用**精简模式**，见 `docs/08-精简模式.md`。立项时由总制片人建议模式，用户决定。
> 原则：**AI 片没法补拍**——台词怎么说、声音怎么设计、镜头怎么覆盖、剪辑点在哪，都在写提示词之前定好。没过门，下游一律不开工。

## 阶段明细

### P0 立项｜总制片人
- **产出**：`00-立项书.md`：媒介、视觉风格、画幅、总时长、集数、目标平台、Seedance 入口、可用分辨率、生图工具（默认 Image 2.5）、声音策略、生成预算、交付规格，**以及模式选择（完整 / 精简）**。
- 有参考导演或参考电影时，在立项书里列出参考清单，进入 P0.5。
- **门0**：用户确认立项书。

### P0.5 参考片研究｜风格参考总监
- **产出**：`00a-参考片研究书.md`：叙事层、视听层、表演层、声音层四层参数 + 禁止滑向的相邻风格。只学方法，不抄镜头。
- 交给：故事架构师与编剧（叙事层）、总导演（总纲）、摄影与美术（视听层）、表演指导与文戏导演（表演层）、台词对白导演（对白风格与沉默）、声音导演（声音层）。
- 与门0 一起由用户确认。

### P1 故事开发｜故事架构师
- **产出**：`01-故事圣经.md` + `02-分场表.md`（每场一行：戏核、五要素、承载物、预计时长、30 秒结构类型、**场次类型：文戏/武戏/特效**、AI 风险）。
- **门1**：每场通过戏剧发动机五要素；剧本医生抽检。

### P2 剧本｜编剧 → 剧本医生
- **产出**：`03-剧本.md`。每场台词量按 30 秒容量控制。
- **门2**：剧本医生业务审 + 合规官合规审，两审全 PASS。

### P3 导演阐述｜总导演
- **产出**：`04-导演阐述.md`：调性、视觉论点（每场一句）、表演尺度、镜头哲学、剪辑节奏、声音方向；每场 30 秒时间建筑与拆条结论；每场由哪位分场导演负责（文戏/武戏/VFX）。
- **门3**：用户确认调性。

### P4 开发（并行）
| 岗位 | 产出文件 |
|---|---|
| 摄影指导（兼灯光） | `05-影像圣经.md`：视场角套装、机器性格、光逻辑、光比、曝光、色温、色彩脚本、质感后缀 |
| 美术指导（兼道具） | `06-场景圣经.md`：场景描述锁、主图与宫格要求、锚点物、空间地图、道具护照与操作机制 |
| 角色造型师 | `assets/characters/<角色>/护照.md`：描述锁、三视图单图规格、变体 |
| 表演指导 | `07-表演母本.md` |
| 声音导演 | `08-声音圣经.md`：音色锁、声音世界、声音母题、静默原则 |
| 台词对白导演 | `08a-台词总表.md`：全片台词按场列出，逐场做容量预审，超容量的场退回编剧或建议拆条 |
- **门4**：总导演审：几份文件属于同一部电影，且与参考片研究书一致。

### P5 资产｜Image 2.5 资产提示词大师 + 资产主管 + 角色造型师 + 美术指导
- 《资产提示词总册》：人物三视图单图、变体、道具状态单图、场景主图、4/6 宫格多视角（站位示意图在 P6 出）。
- 用户用 Image 2.5 出图 → 资产主管登记 → 角色压力测试 10/10 → 其余由总导演签字。
- **门5**：资产锁定；有任何 draft 资产的场，禁止生成视频。

### P6 分镜与调度（逐场）
- 分场导演（文戏/武戏/VFX，按场次类型启用）出调度设计；台词对白导演出台词时间表；声音导演出逐镜声音设计。
- 分镜师汇总成镜头卡，设计首帧/关键帧，提出站位示意图需求；图由 Image 2.5 大师写提示词、资产主管登记。
- **门6**：总导演审创作，剪辑调色师做**剪辑预审**（覆盖够不够剪、接缝能不能接、节奏对不对），两人都签才过。

### P7 编译｜Seedance 编译师
- 十二段式提示词 + 素材接线单 + 界面参数 + 一次成片签字单。
- 五道内部关：时间轴与节奏 / 摄影、调度与表演 / 参考与连续性 / 台词、声音与特效 / 任务与参数。

### P8 生成前审核｜资产主管 + 场记 + 提示词质检官 + 合规官 + 总导演
- 资产主管对账与规格预检 → 场记（连续性、台词逐字）、提示词质检官（红色一票否决）、合规官、总导演。
- **门7**：四签放行。

### P9 生成与审片
- 用户授权花费后提交。原始输出存 `generations/`，入选存 `selects/`。
- 审片分维度打分：表演指导打表演（D3），台词对白导演和声音导演打台词与声音（D7，取低分），场记打空间连续（D4），审片质检员打其余维度并汇总判决。
- 不合格 → 故障分类 → 只改一行 → 重生成 → 记日志；10–15 版不成 → 退回分镜简化。
- **门8**：每条达到合格线。

### P10 后期｜剪辑调色师 + 后期声音与混音师
- 剪辑调色师：只用 selects；粗剪 → 精剪 → 调色 → 字幕 → 导出。
- 后期声音与混音师：对白清理、接缝环境声、拟音、配乐、混音、响度。
- **门9**：成片质检。

## 审核工作流（所有门禁通用）

```
岗位产出 → 写入文件 → 业务审（对应审核岗位）→ 合规审（合规官）
   → 两审全 PASS → 进入下一阶段
   → 任一 FAIL → 合并全部意见 → 原岗位一次性修改 → 覆盖写入 → 重新两审
```

## 返工传播规则

总制片人维护 `production.json` 的依赖关系：
- 改参考片研究书 → 导演阐述与各圣经重新核对。
- 改剧本某场 → 该场导演阐述、调度、台词时间表、分镜、提示词全部 `stale`。
- 改台词 → 该场台词时间表、提示词 `stale`。
- 改角色护照或三视图 → 该角色出场的所有提示词 `stale`，资产重新压测。
- 改空间地图或站位 → 该场所有提示词重新编译。
- 改音色锁 → 该角色说话的所有提示词 `stale`。

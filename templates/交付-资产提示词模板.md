# 《<片名>》资产提示词

> 用法：按下表顺序出图（16:9）。每张图的"推荐模型"列是首选出图模型和理由（选型见 `docs/10`）；把对应代码块整块复制到该模型——```text 给 GPT Image（Image 2.5），```banana 给 Nano Banana，```seedream 给 Seedream / 即梦，```mj 给 Midjourney。需要参考图的，先上传表里写的那张已出好的图。
> 接了 API 的话一条命令批量出：`python3 -I tools/image_gen.py 交付/01-资产提示词.md --out 交付/资产图`（先加 `--dry-run` 看每张走哪个模型、哪个接口）。
> 出完一张，按"出图后检查"看一眼，不合格就换种子重出。全部出完后，按《Seedance 提示词》里每条的上传清单使用。
> 共 <N> 张：人物 <a> 张、道具 <b> 张、场景 <c> 张、场景多视角 <d> 张。

**通用规则**：资产图的光和调色按本片风格配方（docs/16），三视图用配方色温的柔和主光加细轮廓光；不写胶片颗粒和毛孔；无任何文字、数字、车标、徽标；人物都是原创成年人，像某位明星就换种子。标 `LOCKED … (verbatim)` 的中文段落是设定原文，不要改。

出图顺序：人物三视图 → 状态变体 → 强表情（需要时）→ 道具 → 场景主图 → 场景宫格 → 站位示意图（多人戏）→ 首帧图（需要时）。

### 1｜@<角色>｜人物三视图

- **用途**：一句话。
- **先上传**：—（或：第 X 张）
- **推荐模型**：Image 2.5（理由一句）；备选 Nano Banana 2
- **提示词**（推荐模型的代码块在前；备选模型另给一个代码块，写法按 `docs/10` 对应章节）：

```text
<16:9 单图：左半正面+背面全身（正面脸为无五官肤色模糊椭圆），右半大尺寸正面头肩像为唯一面部依据；中性灰背景平光；
LOCKED 角色描述锁 (verbatim)：……>
```

- **出图后检查**：
  - 右侧头像清楚，左侧正面脸是模糊椭圆；
  - 服装、配件与描述锁逐项一致，无文字标志；
  - ……
- **Seedance 引用语**：`@图片N — 「<角色>」：脸只从右侧大头像取；体型、服装、鞋、配件从左侧正面与背面全身像取；正面全身像的模糊椭圆不是脸，不要还原它；不继承灰色背景与三视图版式。`

（道具：`保留……的形状和比例；全片只有这一件；不继承灰色背景与并排版式。`
 场景主图：`只取空间、材质与光源位置；不作首帧，不继承构图、角度与调色；本条的光照以【光照与色彩】段为准。`
 场景宫格：`只取空间结构、家具/地标位置、材质与光源方向，用于不同机位下保持同一地点；不作为首帧，不继承宫格版式与分格。`）

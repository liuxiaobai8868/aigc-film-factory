# 长片续写段模板（超过 30 秒）

> 方法见 `docs/07-30秒以上长片衔接.md`。三种段型，选一种用。

## 一、关键帧续写段（分镜拼接 + 截图交接，最常用）

```text
【参考映射】
@图片1 是上一条的人物站位全景截图，只取站位、空间与道具状态；@图片2 是上一条的尾帧截图，只取剧情状态与光线。
截图中的面部可能模糊：所有人的脸只从设定图取，不要把截图里的模糊迁移到角色上。
@图片3 定义「角色A」的脸、发型与五官（清晰面部图）；@图片4 是角色A正反面角色卡，锁定服装与鞋。
@图片5 定义「角色B」……
冲突优先级：站位与空间以 @图片1 为准；脸与服装以设定图为准。

【场景上下文】
延续上一段剧情：【一句话梗概】。没有多余情节。共 N 个镜头，按顺序全部出现。

【人物与物体对应】
画面共 X 人：A 在最前方；B 在后方左侧……
配角只作背景，不参与动作，不增加台词或单独的反应镜头。
本段说话/受击的对手固定为【某人，带一个可见标记】，全程是同一个人。
道具：【道具】在【谁】手里，状态【……】；只有一个。

【角色锚点】（与上一段逐字一致，复制，不重写）
【视觉风格】（与上一段逐字一致）延续前段的质感、光线、色调与环境。
【空间地图】（与本场其他条逐字一致）
【时间轴】（从 0 秒起算）……；在【稳定画面】上结束，方便剪辑。
【声音】开头 1 秒接住上一段最后一句/最后一个声音：……
【肯定约束】……
```

## 二、连续长镜头接力段（无缝，停在动作中途）

```text
【参考绑定】（全片同一份，逐字复制）
【全局前缀】（质感 / 主角锁 / 道具形态 / 色彩纪律 / 重量与接触阴影，逐字复制）
【摄影、灯光与空间锁定】（逐字复制；后面要用的地标、巨物、道具开场就可见）

【第 K 段｜标题】
续写起点：【每个人、每件东西此刻的精确状态：谁正在做什么动作的哪一半、在哪、面朝哪；哪些东西已经损坏/倒地】。以上状态全部继承，不重置。
0–4 秒｜小标题：……
4–8 秒｜小标题：……
8–12 秒｜小标题：……
12–15 秒｜小标题：……
段尾：【停在一个动作的中途，例如"正在落脚""正在转身"，写清此刻的位置与镜头方向】。下一段从这个动作接着完成。

【全片音频与连续性约束】（逐字复制）
```

## 三、原生视频延长

```text
参考 @视频1 的原始内容，在原片【之后】续写【N】秒。原视频内容保持不变，本提示只作用于新增的 N 秒。
承接边界帧：【人物位置、身体朝向、动作趋势、镜头运动方向与速度、光线、环境声】。
新增内容：【……】，最终状态：【……】。
动作和镜头自然衔接，不硬切，不重置站位，人物与道具不凭空出现或消失。
```
（前延时写"在原片【之前】续写，新增片段结束在原片第一帧的画面上"。）
